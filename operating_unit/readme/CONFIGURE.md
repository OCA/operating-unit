To configure this module, you need to:

- Assign *Multi Operating Unit* group to user.
- Go to *Settings / Users & Companies / Operating Units* and create
  Operating Units.

To set the operating units granted to new users of a company:

- Go to *Settings / General Settings / Permissions / Default Operating
  Units* and select the allowed operating units and the default one
  (the default one is always allowed).
- If no default is set for the company, new users get the default
  operating unit of the user creating them.
